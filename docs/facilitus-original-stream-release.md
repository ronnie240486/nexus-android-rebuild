# Facilitus — runtime original do NEXUS

Esta entrega é um único APK reconstruído a partir do NEXUS.apk original. Os quatro arquivos DEX foram preservados byte a byte, assim como as bibliotecas nativas de reprodução, Activities, player, recursos de catálogo, login, listas, EPG, busca, favoritos, configurações e demais módulos do runtime original.

As alterações são somente de recursos: o label visível passou para Facilitus, o ícone foi substituído pelo asset Facilitus, o `Pre_launcher` original recebeu o logo e a mensagem de boas-vindas, e o identificador na tela original de ativação pode ser selecionado para copiar. O Application, package, Pre_launcher, player e protocolo do NEXUS não foram substituídos.

O package continua `cn.dolit.nexus` para manter as referências internas do runtime. Como a assinatura é nova, desinstale a versão anterior antes de instalar este APK. A build foi alinhada, assinada e verificada. Não há dispositivo Android conectado neste ambiente para validar a abertura física.
